# Network Protocols & Packet Transition Analysis

## 📝 What I Did
I built a Local Area Network (LAN) topology consisting of 3 PCs connected through a centralized Cisco Switch. I used the simulation mode to monitor and
track how network protocols and data packets transit directly from one PC to another across the switch ports.

## 💡 What I Learned
I learned how a Layer 2 Switch filters and forwards traffic. I observed how the switch builds its MAC address table to learn where each PC is located,
ensuring that data packets are sent directly to the destination PC instead of broadcasting to everyone.

## 🌍 Real-World Application
This is the foundational building block of every local office network in the world. Understanding how packets move through a switch helps network engineers monitor
local data traffic, secure departmental communications, and troubleshoot basic connectivity issues inside the building
